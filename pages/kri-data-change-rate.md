# Data Change Rate

*This KRI flags sites and countries with a high rate (low outliers are not of interest for this KRI) of data point changes (fields with +1 change), which may indicate "sloppy" data entry process at the site resulting in multiple corrections/changes to the data points.*

---

## Steps to Perform the Review

1. In the KRI Report by Site, review the Data Change Rate scatter plot for outlier sites in amber/red.

   {: .example }
   > Here site 21274 has a 16.3% data change rate, i.e., 16.3% of data fields have had 1 or more change.

   ![Data change rate scatter plot]({{ site.baseurl }}/assets/images/image36.png)

---

## Investigate Signals

1. Review trending. If the trend is worsening, no change, or if there has been any improvement via the Time Series timeline.

   {: .example }
   > Here you can see the trend has slightly improved over the past 3 months. In this case, prior escalations should be reviewed to confirm if action has already been taken with the site. If action has been taken in a case like this, no action may be required.

   ![Data change rate trend]({{ site.baseurl }}/assets/images/image37.png)
