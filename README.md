# GSM Guide: Central Monitoring Job Aid

This repository contains a Jekyll-based job aid for centralized monitoring guidance.

## Local Preview

1. Install dependencies:
   - Use Ruby 3.3 (or another Ruby 3.x release compatible with the Gemfile)
   - `bundle install`
2. Start the site locally:
   - `bundle exec jekyll serve`
3. Open:
   - `http://127.0.0.1:4000/gsm.guide/`

## Publishing

The site is deployed automatically with GitHub Actions when changes are pushed to `main`.
